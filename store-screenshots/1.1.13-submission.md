# Ping 1.1.13 — App Store submission

## What's New in This Version

One simple way to plan anything
• New Event does it all: invite people, or invite nobody and keep it just for you. You can invite people any time later.
• Mark an Important date, like a birthday or anniversary, and it repeats every year with a reminder.
• Set a reminder for any event when you create it.

A better calendar
• Week view opens on today, shown wide, with the coming days beside it.
• Hold any event to drag it to a new time or day, including repeating events.
• Tap a calendar item to hide it.

Events that travel with you
• Events keep the time you set for the place they're happening, so a trip's plans don't shift when your phone changes time zones.

Plus simpler wording throughout and small fixes.

## App Review Notes

Ping is an event-planning app for families and friends: create an event, invite people from your contacts, track RSVPs, and coordinate what each guest brings.

What's new in 1.1.13:
1. Create → New Event is now the only way to make an event. With nobody invited it saves privately (one Save button); inviting people switches to Send.
2. Under New Event → More options: "Important date" saves a yearly item to the phone calendar (Calendar permission) with an annual reminder (Notification permission). "Remind me before" schedules a local notification.
3. Week view: hold an event to drag it. Repeating phone-calendar items ask "This Event Only / All Future Events".
4. Events store a time zone so times stay correct while traveling.

Permissions, all requested only when the related feature is used:
• Contacts: to invite people. A Ping screen explains this before the system prompt.
• Calendar: to show your phone calendar next to Ping events (Settings → Phone calendar), and to save Important dates.
• Location (approximate): Discover, to show local events.
• Notifications: event reminders and invite updates.

Discover: listings currently cover Utah and Boise, Idaho. Outside those areas Discover shows a "not in your area yet" card with a "Let me know" button. This is expected.

Ping is free to use. A host can choose to sell tickets for an in-person event listed on Discover; those payments go through Stripe because they're for real-world events (Guideline 3.1.3(e)). The demo account has no paid events.

Account deletion: profile menu → Settings → Delete Account.
